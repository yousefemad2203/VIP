# VIP Luxury Perfumes — GitHub Pages

موقع متجر عطور عربي متجاوب، مع معرض رفوف ثلاثي الأبعاد بتفاعل النقر، تفاصيل منتج، تصنيفات، سلة مشتريات، وطلب عبر واتساب.

## التشغيل والنشر
1. فك ضغط الملف.
2. ارفع الملفات الأربعة (`index.html`, `style.css`, `script.js`, `README.md`) إلى مستودع GitHub Pages.
3. فعّل GitHub Pages من Settings → Pages إذا لم يكن مفعلاً.

## تخصيص رقم واتساب
رقم واتساب الحالي داخل `index.html` و`script.js` هو `201147996966`. غيّره في الرابطين إذا احتجت رقمًا آخر، باستخدام رمز الدولة والأرقام فقط.

## إضافة المنتجات الحقيقية
المنتجات الستة وأسماؤها وأسعارها الحالية أمثلة تجريبية. عدّل بطاقات المنتجات في `index.html` (الاسم والوصف والسعر والتصنيف) وحدّث بيانات `productInfo` في `script.js` لمزامنة وصف نافذة العرض. لا تستخدم الأسعار التجريبية للبيع الفعلي.

## ملاحظات
- رفوف العرض مبنية بـ CSS 3D وتعمل دون مكتبات خارجية.
- الضغط على زجاجة يفتح عرضًا مكبّرًا مع حركة إخراج من الرف، ويمكن إضافة المنتج إلى الحقيبة.
- الطلبات تفتح واتساب برسالة تفاصيل السلة. لا يوجد دفع إلكتروني أو إدارة مخزون أو شحن تلقائية.
- لا تزال صور الزجاجات رسومات CSS وليست صور منتجات حقيقية؛ أضف صور منتجاتك الفعلية عندما تكون جاهزة.
